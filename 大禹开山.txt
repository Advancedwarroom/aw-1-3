## 一、核心机制：山道不是新地形，是山的"改写态"

你引擎里山=999 的格子。开天辟地的关键一步：**不开新地形，给山格加一个"被开凿"状态**——

```
Mountain(999 不可通行)  ──开凿──▶  Mountain.carved=true（山道）
                                    ├─ 步兵/轻甲：移动耗 3（陡坡）
                                    ├─ 车辆：耗 5~6 且仅限"拓宽"过的段
                                    └─ 寻路/AI/编辑器全自动认（移动表一改，全局通了）
```

为什么用**状态覆写**而不是新 GridType：① 寻路/AI/补给/雾战零改动（成本表驱动）；② 山的属性（防御星/视野遮挡/不可建造）全保留——你还是趴在山上，只是山被你咬穿了；③ 你的 `terrainMoveCostOverrides` 哲学同构：**格子被谁怎么改，全是数据**。

## 二、"山脉移动模式"——单位侧（两种开法，全 Export）

**A. 静态开凿（愚公式）**：矿工/工兵对相邻山格执行"开凿"（接你现成的建造进度条 20/20、两回合），完工留永久山道。Neoseeker 那"四个矿工围山"的 2002 年老点子，在这落地生根。

**B. 行进开凿（大禹式/你点名的"移动模式"）**——这是你要的魂魄：

```
单位Export：mountainCarveMode
  开启后：单位进入山格合法（不再被999拒）；
  每踏入一格山：当场结算开凿——
    · 该格永久变山道（写 carved 状态）
    · 本格移动耗翻倍 + 扣燃油/扣"体力池"（接统一基底：开凿=一个操作，
      自己的池/自己的冷却——A操作不拖B的老规矩照守）
    · 出山自动关闭或保持（Export 定）
  效果：你的军队从太行山肚子里走过一趟，身后就是一条公路。
```

## 三、Export 规格（直挂现有体系）

```csharp
[ExportGroup("山脉移动·开道")]
canCarveMountains = false        // 总开关（矿工/犀牛推土车/开道车各配）
carveModeManual = true           // 手动按钮切换 还是 进山自动开
carveCostPerCell = 500           // 资金/格（愚公也得吃饭）
carveFuelPerCell = 3             // 燃油/格
carveMoveCost = 4                // 山道内的移动耗（写进被凿格的成本覆写）
carveWiden = false               // 拓宽：车辆也能走（耗更高）
carveInstant = false             // 行进即凿(大禹式) / 停驻两回合(愚公式)
carveDebrisPush = true           // 开凿碎岩触发推动模块（落石伤人！接PushRuntime）
carveOnlyFoot = true             // 仅限步兵系（轻探路）还是装甲开道车也能
```

## 四、联动矩阵（全是现成的桥）

| 系统 | 咬合点 |
| --- | --- |
| 统一基底 | 开凿=受管操作：体力池/每回合米数/冷却——一次装修全享受 |
| 推动模块 | 碎岩滚落=一次自动推动判定（山道开通那格，山脚的敌人可能被砸） |
| 天气 | 大雪封山道：积雪 N 回合覆盖开凿态（得复凿）——老天爷 vs 愚公 |
| 雾战 | 山道里的单位仍有地形防御，但**暴露**——隧道出口就是伏击口 |
| 历史梗 | 你挖的路**不分敌我**：敌军也能走你凿的山道——战略双刃剑，这戏剧性是白拿的 |
| 多格单位 | 战象/抬枪队走山道？拓宽开关说了算 |

## 五、三步落地

1. **P1 山道态**：GridType 状态位+移动成本覆写+编辑器笔刷（凿/复山）+存档；
2. **P2 开凿行动**：静态（建造进度条）＋行进（移动模式）双形态+统一基底接管；
3. **P3 戏剧层**：落石推动/积雪覆盖/敌军借道 AI 权重。
